# MEDIREG AI 운영진 기능 설명서

MEDIREG AI의 기능을 설명하는 문서입니다. 각 기능이 무엇을 하는지, 화면 어디에 있는지, 어떤 제한이 있는지를 정리했습니다. 실제 코드를 보고 확인한 내용이며 기준일은 2026년 9월 23일입니다. 버튼과 메뉴 이름은 화면에 보이는 그대로 [대괄호]에 넣었습니다.

기능이 바뀌면 개발 쪽에서 이 문서도 함께 고칩니다.

---

## 1. 서비스 개요

MEDIREG AI는 의료 규제에 관한 질문에 법령, 고시, 판례, 가이드라인을 근거로 답하는 AI 상담 서비스입니다. 지금은 클로즈 베타 기간이라 초대받은 이메일로만 이용할 수 있습니다.

주요 기능은 다음과 같습니다.

- 질문하기: 규제 질문에 근거를 검색해 인용과 함께 답합니다.
- 심층 보고서: 대화 내용을 바탕으로 컨설팅형 보고서를 만들어 메일로 보냅니다.
- 서류 작성: 법령 별표나 서식을 대화로 채워 원본 서식 파일로 내려받습니다.
- IRB·DRB 심의 상담: 연구가 심의 대상인지 예비 판정하고 절차와 서류를 안내합니다.
- 저장한 근거: 답변의 인용을 모아 두고, 법령이 개정되면 알림을 받습니다.

### 용어

| 화면 표기 | 뜻 |
|---|---|
| 대화 | 채팅 한 건입니다. 사이드바 '대화' 목록에 쌓입니다. |
| 심층 보고서 | 대화 내용을 근거로 백그라운드에서 만드는 컨설팅형 보고서입니다. |
| 작성한 서식 | 법령 별표나 서식을 채워 만든 서류입니다. |
| 저장한 근거(근거 라이브러리) | 답변에 달린 인용을 북마크로 모아 둔 개인 목록입니다. |
| 보관 | 작성한 서식을 대화가 지워져도 남도록 해 두는 기능입니다. 서식에만 있고 보고서에는 없습니다. |
| IRB/DRB | 연구 심의 상담 모드입니다. |

## 2. 화면 구성

왼쪽 사이드바에는 위에서부터 다음 항목이 있습니다.

1. 새 대화
2. 심층 보고서(N): 모든 대화에서 완성된 보고서 목록
3. 작성한 서식(N)과 그 오른쪽의 [관리]
4. 대화: '대화 검색 (제목·내용)' 검색칸과 대화 목록
5. 저장한 근거
6. 이용 안내, 그리고 그 오른쪽의 [둘러보기](30초 화면 안내)
7. 사용량 막대, 계정 메뉴(내 데이터·개인정보, 로그아웃), 이용약관과 개인정보처리방침 링크

상단에는 사이드바 열기 버튼, 대화 제목(제목 수정 가능), 🔔 알림, 오른쪽 패널 열기·닫기 버튼이 있습니다. 가운데에 대화와 입력창이 있고, 오른쪽 패널에는 인용 출처의 상세 내용과 보고서 진행 상황이 나옵니다.

## 3. 질문하기

### 첫 화면

인사말과 "궁금한 의료 규제를 물어보세요." 문구 아래에 예시 질문 다섯 개가 목록으로 나옵니다.

- 의료기기 품목허가 절차와 제출 서식
- 의료기기 광고 심의 기준
- 임상시험 IND 승인 절차
- 비대면 진료 관련 판례·유권해석
- 연구 심의 대상인지 확인하기

예시를 누르면 이 질문으로 알 수 있는 내용과 미리보기가 담긴 창이 뜹니다. [이 질문으로 시작]을 누르면 입력창에 질문이 채워지고, 사용자가 확인한 뒤 보냅니다. 추가 정보를 적는 칸은 품목허가와 연구 심의 예시에만 있습니다.

### 입력창

Enter로 보내고 Shift+Enter로 줄을 바꿉니다. 답변이 나오는 중에는 Esc나 정지 버튼으로 멈출 수 있습니다. 한 번에 32,000자까지 입력할 수 있으며, 24,000자를 넘기면 글자 수가 표시됩니다.

입력창 아래에는 첨부(📎), [IRB/DRB], [피드백], [심층 보고서] 버튼이 있고 오른쪽에서 답변 수준(기본, 전문가, 쉬움)을 고릅니다. [심층 보고서]는 첫 질문을 보낸 뒤에 나타납니다. 입력창 아래에는 "AI가 생성한 참고 정보이며 법률자문이 아닙니다"라는 문구가 항상 표시됩니다.

### 파일 첨부

문서를 첨부하면 그 내용을 바탕으로 질문할 수 있습니다. 📎 버튼을 누르거나 파일을 끌어다 놓으면 됩니다.

| 항목 | 내용 |
|---|---|
| 지원 형식 | 텍스트가 있는 PDF, DOCX, HWPX, TXT, MD, CSV |
| 지원하지 않는 형식 | 예전 HWP(.hwp), DOC, 스캔한 PDF, 암호가 걸린 PDF. 올리면 다른 형식으로 저장하라는 안내가 뜹니다. |
| 한도 | 한 번에 3개, 파일당 15MB, 파일당 12만 자까지 읽습니다. 넘으면 앞부분만 쓰고 "일부"라고 표시합니다. |
| 개인정보 | 원본 파일은 서버에 남기지 않습니다. 파일에서 뽑아낸 글에도 개인정보 가림이 똑같이 적용됩니다. |

### 검색과 답변

규제에 관한 질문이면 항상 근거를 먼저 검색한 뒤 답합니다. 인사나 잡담에는 검색하지 않습니다. 답변은 보통 15~20초 걸립니다.

검색 대상은 법령, 행정규칙(고시), 자치법규, 판례, 해석례, 가이드라인, 급여기준 같은 행정규칙 첨부 자료입니다. 규제 질문이면 웹 검색도 함께 합니다. IRB/DRB 모드에서는 웹 검색을 하지 않습니다.

검색하는 동안 "근거 찾는 중…"이 표시되고 [처리 과정 보기]로 과정을 펼쳐 볼 수 있습니다. 질문이 모호하면 "추가 확인이 필요해요" 카드로 되묻고, 답변이 길어 중간에 끊기면 [이어서 작성] 버튼이 나옵니다.

### 답변 화면

| 요소 | 설명 |
|---|---|
| 신뢰도 배지 | 답변 맨 위에 나옵니다. 인용을 원문과 대조해 확인한 비율로 정하며, 80% 이상은 높음, 30~79%는 보통, 30% 미만은 낮음입니다. 인용이 없으면 나오지 않습니다. |
| 인용 번호 [n] | 본문 속 번호입니다. 법령, 행정규칙·고시, 판례·해석, 가이드라인, 별표·서식, 웹 자료마다 색이 다르고, 답변이 끝난 뒤에 한꺼번에 나타납니다. |
| 출처 N건 | 답변 아래 접었다 펼 수 있는 목록입니다. "법령 7 · 웹 2"처럼 종류별 건수가 나오고, 폐지, 구법, 시행 전, 개정 예정 같은 상태도 표시됩니다. |
| 오른쪽 출처 패널 | 인용 번호나 출처를 누르면 열립니다. 조문 본문과 검증 여부를 보여 주고 [별표 미리보기], [HWP 다운로드], [이 서식으로 작성], 원문 링크, [근거 라이브러리에 저장] 버튼이 있습니다. |
| 관련 서식 N건 | 근거 법령에 딸린 서식을 모아 보여 줍니다. 항목마다 [미리보기], [원본], [이 서식으로 작성]이 있고 네 개씩 [더 보기]로 늘립니다. |
| 이어서 물어볼 만한 것 | 다음 질문 제안입니다. 누르면 입력창에 채워지고, 보내는 것은 사용자가 합니다. 보고서 제안에는 "보고서 · 5~20분"이 붙습니다. |
| 절차 타임라인 | 세 단계 이상의 절차를 설명하는 답변에 붙고, 단계마다 체크할 수 있습니다. |
| 답변 아래 버튼 | Word로 내보내기, 복사, 좋아요(👍), 아쉬워요(👎)가 있습니다. 아쉬워요를 누르면 의견을 적을 수 있습니다. 답변을 다시 만드는 버튼은 없습니다. |
| 인용 신고 | 인용 번호나 출처 항목을 누르면 뜨는 작은 창의 [이 인용 신고]로 잘못된 인용을 알립니다. 검증 문장이 있는 인용에만 나옵니다. |

"근거 법령 네트워크 보기"는 설정으로 켜고 끄는 기능이라 운영 화면에서는 꺼져 있을 수 있습니다.

### 개인정보 자동 가림

질문과 첨부 파일에 들어 있는 개인정보는 AI에 보내기 전과 저장하기 전에 자동으로 가려집니다. 질문 자체를 막지는 않습니다.

가리는 대상은 주민등록번호, 전화번호, 이메일, 카드번호, IP, 여권번호, 사업자번호, 차량번호 같은 정해진 형식의 정보와, 탐지 모델이 찾아내는 이름, 주소, 생년월일, 나이입니다. 탐지 모델을 쓰는 만큼 모든 경우를 잡아낸다고 보장하지는 않습니다.

가린 내용이 있으면 "입력에 포함된 개인정보를 자동으로 제거했어요" 알림이 뜹니다. 검색어가 가려진 경우에는 "'OO'이(가) 개인정보로 감지되어 검색에서 제외됐어요"라는 알림과 함께 [오류 신고] 버튼이 12초 동안 보입니다. 신고하면 다음 질문부터 그 단어는 가리지 않고, 운영자가 나중에 검토합니다. 전화번호와 주민등록번호는 신고할 수 없습니다.

### 그 밖의 기능

- [피드백]: 켜고 보내면 AI 답변 대신 운영팀에 의견이 전달됩니다. 최대 2,000자입니다. 답변마다 있는 좋아요·아쉬워요와는 별개입니다.
- 대화가 12번 넘게 오가면 새 대화를 시작하라는 안내가 뜹니다.
- 이용자가 많을 때는 "지금 이용자가 많아 응답이 느릴 수 있어요"가 표시됩니다.

## 4. 대화 목록과 검색

대화 목록은 고정한 대화가 먼저 나오고 나머지는 최근 순입니다. 날짜별 구분은 없습니다.

'대화 검색 (제목·내용)' 칸은 제목을 바로 걸러 주고, 내용 검색은 두 글자부터 됩니다. 검색 결과는 대화 목록으로만 보여 줍니다.

대화 오른쪽 ⋮ 메뉴에는 [상단 고정](고정된 대화는 [고정 해제]), [이름 변경], [삭제]가 있습니다. 대화를 지우면 그 대화에서 만든 서식 중 보관하지 않은 것도 함께 지워지고, 다시 살릴 수 없습니다.

Ctrl+K(Mac은 ⌘K)를 누르면 빠른 이동 창이 열립니다. 여기서 새 대화를 시작하거나 저장한 근거를 열 수 있고, 대화를 제목과 내용으로 찾을 수 있습니다. 내용으로 찾은 대화는 검색어가 든 문장도 함께 보여 줍니다. 아무것도 입력하지 않으면 최근에 본 조문 다섯 개가 나오며, 누르면 원문 사이트로 연결됩니다.

## 5. 심층 보고서

지금까지 나눈 대화를 근거로 컨설팅형 보고서를 백그라운드에서 씁니다. 보고서는 대화창에 나오지 않고 사이드바, 오른쪽 패널, 메일로 받습니다. 채팅과 보고서를 일부러 나눠 두었습니다.

| 항목 | 내용 |
|---|---|
| 시작하는 법 | 입력창 아래 [심층 보고서]를 누르고 목적을 고릅니다. 목적은 종합(기본), 허가 전략, 규제 요약, 변경 대응 네 가지입니다. '이어서 물어볼 만한 것'의 보고서 제안을 눌러도 됩니다. |
| 조건 | 대화에 근거 인용이 달린 답변이 한 번 이상 있어야 하고, 답변이 나오는 중에는 시작할 수 없습니다. |
| 걸리는 시간 | 화면 안내는 "보통 5~20분, 길면 1시간"입니다. 서버 상황에 따라 달라집니다. |
| 진행 상황 | 오른쪽 패널에 경과 시간과 세 단계(질문 나누기, 자료 모으기, 보고서 쓰기), 대기 순서가 나옵니다. [중단]을 누르면 그때까지 만든 내용은 남지 않습니다. 보고서를 만드는 동안에도 채팅은 계속할 수 있습니다. |
| 대기 | 서버 전체에서 한 번에 한 건씩 쓰고 나머지는 순서대로 기다립니다. 한 대화에서는 한 번에 한 건만 만들 수 있고, 대기 중인 요청이 너무 많으면 "보고서 큐가 가득 찼습니다"가 뜹니다. |
| 구성 | 제목, 목차, 작성 기준일 아래에 개요, 주제에 맞춘 본론 2~5개, 결론 및 권고가 이어집니다. 표를 많이 쓰고 문장마다 인용 번호를 답니다. 규제 요약은 짧게 씁니다. |
| 결과 보는 곳 | 사이드바 '심층 보고서'를 누르면 미리보기 창이 열리고, 오른쪽 패널 카드에서 Word나 Markdown으로 내려받거나 평가하거나 지울 수 있습니다. 미리보기 창에서는 PDF로 인쇄해 저장할 수 있습니다. |
| 완료 알림 | 화면 알림과 함께 가입한 이메일로 Word 파일이 첨부된 메일이 갑니다. 메일을 끄려면 [심층 보고서] 창 맨 아래 "완료 시 이메일로 받기 (Word 첨부)"를 해제합니다. 다른 설정 화면에는 이 항목이 없습니다. |
| 보관 기간 | 만든 지 30일이 지나면 목록, 제목, 내용이 모두 지워집니다. 보고서에는 보관 기능이 없어서, 계속 쓸 보고서는 메일로 받은 Word 파일을 따로 보관해야 합니다. |
| 직접 지우기 | 사이드바나 카드에 마우스를 올리면 휴지통 아이콘이 나옵니다. 확인을 거쳐 지우며 되살릴 수 없습니다. |
| 점검 중일 때 | 운영자가 보고서 기능을 잠시 멈추면 버튼이 꺼지고 "보고서 기능 점검 중"이 표시됩니다. 채팅과 검색은 그대로 됩니다. |

## 6. 서류(서식) 작성

법령 별표나 서식을 대화로 채워서 원본 서식 파일 모양 그대로 내려받는 기능입니다.

| 항목 | 내용 |
|---|---|
| 시작하는 법 | 답변 아래 '관련 서식 N건'이나 오른쪽 출처 패널에서 [이 서식으로 작성]을 누릅니다. 자료 종류에 따라 [이 별표로 작성], [이 문서로 작성]으로 보이기도 합니다. 작성 화면은 몇 초 안에 열립니다. |
| 다시 열기 | 입력창 위의 "작성 중인 서류" 표시(지금 대화의 가장 최근 서류)나 사이드바 '작성한 서식'에서 엽니다. |
| 작성 화면 | 왼쪽에 채울 항목, 오른쪽에 작성 도우미 대화가 있습니다. 도우미 대화는 저장되지 않습니다. 새 탭에서 크게 열 수도 있습니다. |
| 채우는 방법 | 도우미에게 말로 알려 주거나(한 문장에 여러 값도 됩니다), 항목을 눌러 직접 입력하거나, ✨ 버튼이나 [✨ 전체 자동 작성]으로 대화 내용을 바탕으로 채웁니다. 근거가 없는 칸은 비워 둡니다. 사업자등록증 같은 서류를 📎로 첨부해 값을 뽑아낼 수도 있습니다(PDF, DOCX, HWPX, TXT, MD, CSV. .hwp는 안 됩니다). |
| 내려받기 | [서식 그대로 내보내기]를 누르면 원본 서식에 입력한 값만 채워서 내려받습니다. 확장자는 원본을 따라 .hwp나 .hwpx입니다. 관보 원본이 없는 서식은 Word 파일로 받습니다. 다 채우지 않아도 내보낼 수 있으며, 빈 칸은 화면에 [확인 필요]로 남고 파일에서는 빈 칸으로 나갑니다. |
| 문제 신고 | 작성 화면 오른쪽 위 🚩 버튼입니다. 항목 추출 오류, 서식이 아님, 내용 불일치, 기타 중에서 고릅니다. |
| 완료 메일 | 서식에는 완료 메일이 없습니다. |

### [관리] 창

사이드바 '작성한 서식' 옆 [관리]를 누르면 열립니다. '전체'와 '보관함' 탭이 있고, 서식마다 제목(별명), 만든 대화, 작성일, 작성 상태(미작성, 작성 중, 완료)가 나옵니다. 만든 대화를 누르면 그 대화로 이동하며, 대화가 지워졌으면 "삭제된 대화"로 표시됩니다. 보기, 내려받기, 보관(책갈피 아이콘), 삭제도 여기서 합니다. 별명은 60자까지 붙일 수 있습니다.

### 보관 규칙

서식은 그것을 만든 대화에 딸려 있습니다. 대화를 지우거나 대화가 90일 기간이 지나 정리되면 서식도 함께 지워집니다. [보관]한 서식만 대화와 관계없이 남습니다. 보고서의 30일 규칙은 서식에 적용되지 않습니다.

### 개인정보 처리

작성 도우미 대화는 외부 AI로 보내지 않고 내부 모델로만 처리하며, 저장하지 않습니다. 입력한 값은 암호화해서 저장하고, 완성 파일은 서버에 두지 않고 내려받을 때마다 새로 만듭니다.

✨ 자동 작성은 설정에 따라 다르게 동작합니다. 내부 모델이 설정되어 있으면 내부 모델을 쓰고, 그렇지 않으면 개인정보를 가린 대화를 외부 AI가 보고 채웁니다.

## 7. IRB·DRB 심의 상담

연구 한 건이 IRB 심의 대상인지, 대상이라면 면제, 신속, 정규 중 어디에 해당하는지 예비 판정합니다. 의료정보데이터를 쓰는 연구는 DRB 해당 여부와 IRB와의 순서도 알려 줍니다. 이어서 절차, 기한, 제출 서류, 이의신청, 승인 후 의무를 안내하고, 의뢰서, DRB 서식, 가명처리계획서, 연구계획서, 동의서 초안을 씁니다.

| 항목 | 내용 |
|---|---|
| 기준 기관 | 제휴대학교병원 한 곳입니다. 다른 기관 사용자에게는 소속 기관 규정이 다를 수 있으니 사무국에 확인하라고 안내합니다. |
| 시작하는 법 | 첫 화면의 '연구 심의 대상인지 확인하기'를 누르거나(연구 개요와 사용 데이터 칸은 비워도 됩니다), 입력창의 [IRB/DRB] 버튼을 켭니다. 버튼은 끌 때까지 켜져 있습니다. 버튼을 켜지 않아도 IRB, DRB, 심의면제, 가명처리계획 같은 말이 들어간 질문은 자동으로 상담 모드로 넘어갑니다. |
| 판정의 성격 | 예비 판정입니다. 판단이 애매하면 보류하고 필요한 정보를 되묻습니다. 최종 판단은 기관 심의 사무국이 합니다. |
| 개인정보 | 상담 내용은 외부 AI를 거치지 않고 내부 모델로만 처리하며 웹 검색도 하지 않습니다. 내부 모델이 점검 중이면 외부로 넘기지 않고 "상담 엔진 점검 중"이라고 안내합니다. |
| 속도 | 일반 채팅보다 느리고, 판정 한 번에 몇 분이 걸릴 수 있습니다. |
| 제공 범위 | 기관 지침 원문 전체나 서식 원본 파일은 주지 않고 요약과 조항 위치만 알려 줍니다. 판정 결과는 답변 본문에 문장으로 나오고 별도 배지는 없습니다. IRB 서식은 원본 파일에 바로 채우는 방식이 아니라 초안(텍스트나 Word)으로 받습니다. |

## 8. 저장한 근거와 알림

### 저장한 근거

답변 아래 출처 목록의 북마크 아이콘이나 오른쪽 출처 패널의 [근거 라이브러리에 저장]을 누르면 저장됩니다. 한 번 더 누르면 저장이 풀립니다. 조문, 별표·서식, 판례 등 답변에 달린 인용을 저장할 수 있습니다.

저장한 목록은 사이드바 '저장한 근거', Ctrl+K의 '저장한 근거 열기', 🔔 알림 창에서 열 수 있습니다. 목록에서는 원문을 열고, 별표·서식 원본을 내려받고, 폴더로 정리하고, 지울 수 있습니다.

저장한 근거는 원래 대화가 지워져도 남고, 자동으로 지워지지도 않습니다. 목록을 파일로 내보내는 기능과 메모 기능은 없습니다.

### 🔔 알림

상단 오른쪽의 🔔은 저장해 둔 법령 조문이 폐지되거나, 개정이 예정되거나, 개정되어 시행일이 바뀌었을 때 건수를 보여 줍니다(최대 9+). 접속할 때 확인하는 방식이라 실시간 알림이나 메일은 아닙니다. 판례, 서식, 웹 자료는 개정 알림 대상이 아니고, 보고서 완료나 공지도 🔔으로 오지 않습니다.

저장 목록 창을 닫으면 해당 항목에 "확인함"이 표시됩니다. 이 표시는 기기마다 따로 기억되고, 🔔의 숫자는 확인과 관계없이 계속 표시됩니다.

## 9. 계정, 개인정보, 보관 기간, 사용량

### 가입과 로그인

클로즈 베타 기간이라 초대받은 이메일만 가입하고 이용할 수 있습니다. 대상이 아니면 "클로즈 베타 대상이 아닙니다. 참여를 원하시면 운영팀에 문의해주세요."가 뜹니다. 문의처는 admin@example.com입니다.

로그인은 이메일과 비밀번호로 하거나, 비밀번호 없이 이메일로 받은 링크를 눌러서 할 수 있습니다(링크는 10분 동안 유효). 소셜 로그인은 없습니다. 로그인 상태는 90일 동안 유지되고, 비밀번호를 다섯 번 틀리면 10분 동안 로그인할 수 없습니다.

### 내 데이터·개인정보

계정 메뉴의 '내 데이터·개인정보'에서 다음을 볼 수 있습니다.

- 계정 정보: 이메일, 가입일, 동의한 약관 버전
- 메일 수신: '서비스 안내 메일'을 끄면 안내 메일과 뉴스레터가 가지 않습니다. 보안이나 장애 같은 꼭 필요한 공지는 계속 갑니다. 마케팅 메일 수신 동의도 여기서 따로 정합니다.
- 프로필: 이름, 소속, 직군(각 60자까지)
- 데이터 보유 기간과 국외 이전 안내
- [회원탈퇴]: 바로 로그아웃되고 다시 로그인할 수 없습니다. 데이터는 보유 기간 동안 보관되며, 되살리려면 운영팀에 문의해야 합니다.
- [계정 삭제 요청]: 바로 지워지지 않고 운영자가 처리한 뒤 메일로 알려 줍니다. 처리되면 되돌릴 수 없습니다.

데이터를 파일로 내려받는 기능은 없습니다. 보고서 완료 메일 설정은 이 화면이 아니라 [심층 보고서] 창에 있습니다.

### 보관 기간

매일 한 번 자동으로 정리합니다.

| 데이터 | 보관 기간 |
|---|---|
| 대화 | 마지막으로 쓴 날부터 90일. 대화 속 인용도 함께 지워집니다. |
| 심층 보고서 | 만든 날부터 30일. 목록, 제목, 내용이 모두 지워집니다. |
| 작성한 서식 | 대화와 함께 지워집니다. [보관]한 서식은 남습니다. |
| 저장한 근거 | 자동으로 지우지 않습니다. |
| 이용 기록(질문, 검색어) | 90일 |

지워진 데이터는 되살릴 수 없습니다. 사용자가 복구할 수 있는 기능은 없습니다.

### 사용량

사이드바 아래쪽 막대가 하루와 한 달 사용량을 보여 주고, 누르면 오늘과 이번 달 사용량, 이번 달 비용이 나옵니다. 베타 기간에는 사실상 제한이 없고, 과도한 사용을 막는 상한만 있습니다. 80%를 넘으면 입력창 위에 경고가 뜨고, 한도를 넘으면 새 질문을 보낼 수 없습니다. 이미 나오고 있던 답변은 끝까지 나옵니다. 하루 한도는 한국시간 자정에, 한 달 한도는 매월 1일에 초기화됩니다.

### 외부 서비스로 가는 데이터

일반 채팅은 개인정보를 가린 뒤 Anthropic(미국)의 AI로 답을 만듭니다. Anthropic에 장애가 있으면 OpenAI(미국)를 대신 쓰고, 웹 검색은 Tavily(미국)에 검색어를 보냅니다. IRB·DRB 상담과 서류 작성 도우미는 외부로 보내지 않고 내부 모델로 처리합니다.

## 10. 안내 페이지

- 이용 안내(/guide): 로그인하지 않아도 볼 수 있습니다. 사이드바의 [이용 안내]를 누르면 새 탭에서 열립니다. 시작하기, 질문하기, 연구 심의, 답변과 근거 읽기, 심층 보고서, 서류 작성, 무엇을 찾을 수 있나, 그 밖의 기능으로 나뉘어 있습니다.
- 둘러보기: 처음 접속했을 때 한 번 자동으로 나오고, 그 뒤에는 [둘러보기]로 다시 볼 수 있습니다. 질문 입력, 첨부, IRB/DRB, 설명 수준, 심층 보고서, 서류 작성, 연구 심의, 개정 알림, 저장한 근거, 빠르게 쓰기 순서로 화면을 짚어 줍니다.
- 업데이트(/updates): 로그인하지 않아도 볼 수 있습니다. 검색·답변, 심층 보고서, IRB·DRB 심의 상담, 서류 작성, 개인정보 보호, 계정·이용, 화면·편의 탭과 검색이 있습니다.
- 업데이트 팝업: 업데이트 내역에 새 글이 올라오면 로그인할 때 가장 최근 글 한 건이 팝업으로 뜹니다. 팝업을 끄고 올린 글은 뜨지 않습니다.
- 공개 페이지 위쪽 메뉴: 소개, 이용 안내, 업데이트가 있고, 로그인 전에는 [로그인]과 [시작하기], 로그인 후에는 [채팅으로]가 보입니다.

## 12. 사용자 흐름

초대부터 탈퇴까지 사용자가 거치는 단계와 단계마다 적용되는 규칙입니다.

### 초대

관리자 화면 [베타 초대]에서 이메일 주소나 '@도메인'을 초대 목록에 넣습니다. 한 건씩도, 여러 건을 한꺼번에도 넣을 수 있습니다. 목록에 넣는 것만으로는 메일이 가지 않습니다.

초대 메일은 관리자가 주소마다 따로 보냅니다. 제목은 "[MediReg AI] 베타 서비스를 시작합니다"이고, 서비스 소개와 함께 '계정 만들기' 버튼이 들어 있습니다. 버튼은 소개 페이지(/landing)로 연결됩니다. 메일 문구는 관리자 화면에서 고칠 수 있고, 보내기 전에 미리보기와 테스트 발송을 할 수 있습니다. '@도메인' 항목에는 보낼 주소가 없어 초대 메일을 보낼 수 없고, 이미 가입한 사람에게는 기본적으로 다시 보내지 않습니다.

가입과 이용에 필요한 것은 초대 목록에 올라 있는지 여부뿐입니다. 초대 메일을 받지 않았어도 목록에 있으면 가입할 수 있습니다. 목록에서 빼면 이미 로그인해 있던 사람도 다음 요청부터 이용할 수 없습니다. 관리자는 목록과 관계없이 항상 이용할 수 있습니다.

### 가입

가입 화면에서 필수로 받는 것은 이메일 하나이고, 이름, 직업, 소속은 선택입니다.

동의 항목은 세 가지입니다. 앞의 두 개는 필수라 체크하지 않으면 가입 버튼이 눌리지 않습니다.

- [필수] 이용약관 및 개인정보 수집·이용에 동의합니다.
- [필수] 개인정보의 국외 이전에 동의합니다.
- [선택] 제품 정보·업데이트 등의 수신에 동의합니다.

초대 목록에 없는 이메일이면 "가입이 허용되지 않은 이메일입니다. 운영팀(admin@example.com)에 문의해주세요."가 뜹니다. 이미 가입한 이메일로 다시 가입하면 오류 없이 인증 메일만 다시 갑니다.

가입하면 "MEDIREG AI 이메일 인증" 메일이 갑니다. 링크는 10분 동안 한 번만 쓸 수 있고, 다시 보내기는 30초 간격으로 할 수 있습니다. 링크를 누르면 비밀번호를 정하는 화면으로 가며, 비밀번호는 8자 이상에 특수문자를 한 개 이상 넣어야 합니다. 비밀번호를 정하기 전에는 다른 화면으로 넘어가지 않습니다.

### 로그인

로그인은 이메일과 비밀번호로 하거나, 비밀번호 없이 이메일로 받은 링크(10분 유효)로 할 수 있습니다. 비밀번호를 잊으면 [비밀번호를 잊으셨나요?]에서 메일 링크를 받아 새로 정합니다. 기존 비밀번호는 새 비밀번호를 정할 때까지 그대로 쓸 수 있습니다.

비밀번호를 다섯 번 연속 틀리면 10분 동안 로그인이 막히고, 비밀번호를 새로 정하면 바로 풀립니다. 로그인 상태는 90일 동안 유지됩니다.

로그인하면 소개 페이지로 이동하고, [시작하기]를 누르면 채팅 화면(새 대화)으로 들어갑니다.

로그인이 막히는 경우는 다음과 같습니다.

| 상황 | 사용자에게 보이는 것 |
|---|---|
| 초대 목록에 없는 이메일 | 비밀번호 로그인은 "클로즈 베타 대상이 아닌 이메일입니다. 참여를 원하시면 운영팀(admin@example.com)에 문의해주세요.", 메일 링크 로그인은 "등록되지 않은 이메일이거나 발송에 실패했습니다." |
| 로그인 중에 초대 목록에서 빠짐 | "클로즈 베타 대상이 아닙니다. 참여를 원하시면 운영팀에 문의해주세요." |
| 탈퇴한 계정 | 로그인은 되지만 이용하려 하면 "탈퇴한 계정입니다. 재가입을 원하시면 운영팀에 문의해주세요." |

### 첫 방문

처음 채팅 화면에 들어오면 30초 화면 안내(둘러보기)가 한 번 자동으로 나옵니다. 그 뒤에는 사이드바의 [둘러보기]로 다시 볼 수 있습니다. 업데이트 팝업은 둘러보기를 마친 다음 접속부터 뜹니다.

프로필을 따로 입력하라는 화면은 없습니다. 가입할 때 적은 이름, 직업, 소속이 첫 로그인 때 자동으로 저장되고, 나중에 '내 데이터·개인정보'에서 고칠 수 있습니다.

이용약관이나 개인정보처리방침이 바뀌어 버전이 올라가거나 필수 동의 항목이 늘면 "서비스 이용 동의" 창이 떠서 다시 동의를 받습니다. 가입 직후 한 번은 가입 화면에서 체크한 내용으로 자동 처리되고, 그 뒤로는 반드시 창에서 직접 동의해야 합니다. 동의하지 않으려면 창에서 로그아웃할 수 있습니다. 동의하지 않은 상태에서는 질문과 보고서 요청이 되지 않습니다(관리자 제외). 현재 버전은 2026년 7월 16일 버전입니다. 서버에서 동의 여부를 확인하기 시작한 2026년 9월 23일 이전에 가입해 동의 기록이 없던 사용자는 자동으로 동의 처리했습니다.

### 이용 중

이용하다가 다음과 같은 상황을 만날 수 있습니다.

| 상황 | 적용 범위 | 사용자에게 보이는 것 |
|---|---|---|
| 이용 동의 안 함 | 질문, 보고서 요청 | "서비스 이용 동의가 필요합니다" 안내와 함께 동의 창이 뜹니다. 동의하면 바로 이용할 수 있습니다. |
| 하루 사용 한도 초과 | 질문, 보고서 요청 | "오늘 사용량 한도에 도달했습니다. 내일 다시 이용 가능합니다." 한국시간 자정에 풀립니다. 대화 목록과 지난 대화는 계속 볼 수 있습니다. |
| 한 달 사용 한도 초과 | 질문, 보고서 요청 | "다음 달 1일에 초기화됩니다." |
| 요청이 너무 잦음 | 모든 요청 | 사용자당 1분에 30회, 1시간에 600회를 넘으면 잠시 막힙니다. |
| 서비스 점검 | 전체(관리자 제외) | 화면 전체에 "지금은 점검 중이에요" 안내가 뜹니다. 관리자에게는 배너만 보입니다. |
| 보고서 기능만 점검 | 보고서 요청(관리자 포함) | "보고서 기능 점검 중입니다. 채팅·검색은 정상 이용 가능합니다." |
| 보고서 대기가 많음 | 보고서 요청 | 기다리는 보고서가 4건 이상이면 "보고서 큐가 가득 찼습니다. 잠시 후 재시도해주세요." |
| 같은 대화에서 보고서 진행 중 | 보고서 요청 | 끝날 때까지 새 보고서를 만들 수 없습니다. |
| 이용자가 많음 | 안내만 | 입력창 위에 "지금 이용자가 많아 응답이 느릴 수 있어요"가 뜹니다. 이용은 그대로 됩니다. |

### 탈퇴와 계정 삭제

'내 데이터·개인정보'에서 두 가지를 할 수 있습니다.

[회원탈퇴]를 누르고 안내를 확인한 뒤 [탈퇴하기]를 누르면 바로 로그아웃되고 이용이 멈춥니다. 데이터는 개인정보처리방침의 보유 기간 동안 보관됩니다. 같은 이메일로 다시 가입해도 이용할 수 없고, 운영자가 관리자 화면에서 계정을 복구해야 다시 쓸 수 있습니다.

[계정 삭제 요청]을 누르고 사유(선택)를 적은 뒤 [삭제 요청 확정]을 누르면 요청이 운영팀에 접수됩니다. 바로 지워지지 않고 운영자가 삭제를 처리합니다. 대화, 심층 보고서, 작성한 서식(보관한 것 포함), 저장한 근거, 평가, 계정 정보를 모두 지우고 초대 목록에서도 뺍니다. 처리가 끝나면 "[MEDIREG AI] 계정 삭제가 완료되었습니다" 메일이 자동으로 갑니다. 삭제된 데이터는 되돌릴 수 없습니다.

### 사용자가 받는 메일

| 메일 | 언제 | 수신 거부 |
|---|---|---|
| 베타 초대 | 관리자가 보낼 때 | 해당 없음(한 사람씩 보냄) |
| 이메일 인증, 로그인 링크, 비밀번호 재설정 | 가입, 링크 로그인, 비밀번호 재설정 때 | 해당 없음 |
| 심층 보고서 완료(Word 첨부) | 보고서가 끝났을 때 | [심층 보고서] 창의 "완료 시 이메일로 받기"로 끔 |
| 서비스 안내, 뉴스레터 | 운영팀이 보낼 때 | '서비스 안내 메일'을 끈 사람, 탈퇴한 사람은 받지 않음. 마케팅 성격이면 마케팅 동의자만 받음 |
| 계정 삭제 완료 | 운영자가 삭제를 처리한 뒤 자동 | 해당 없음 |

운영팀이 한 사람에게 보내는 개인 알림은 메일이 아니라 서비스 안의 팝업으로 뜹니다. 주간 이용 보고서는 관리자에게만 가는 메일입니다.
