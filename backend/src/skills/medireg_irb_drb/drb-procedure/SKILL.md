# DRB 절차·서류·기한 안내

## 이 스킬의 경계

**이 스킬은 판정하지 않는다.** 심의 종류가 정해진 상태를 전제로 절차와 서류를 안내한다.

- 사용자가 자신의 심의 종류를 모르면 → **`drb-triage`를 먼저 호출**한다
- 서식을 실제로 작성해야 하면 → `drb-form-filler`
- IRB 절차는 → `irb-procedure`

## 절대 규칙

1. **서류 목록을 임의로 줄이거나 늘리지 않는다.** references에 있는 목록 그대로 제시한다.
2. **"해당하는 경우"로 표시된 서류는 그 조건을 함께 표기한다.**
3. **기한은 반드시 기준일을 명시한다.** "1개월 전"이 아니라 "승인유효기간 만료일 기준 1개월 전".
4. ⚠️ **IRB의 기한 규정과 섞지 않는다.** 특히 **이의신청은 DRB 15일 / IRB 6개월**로 크게 다르다.
5. **IRB 승인이 전제되는 과제**는 지속심의 시 IRB 연장 확인자료가 추가로 필요하다는 점을 빠뜨리지 않는다 (제29조④).

## 사용 방법

| 사용자가 알고 싶은 것 | 읽을 파일 |
|---|---|
| 신청 유형별 제출서류·별지서식 목록 | `references/drb-documents.md` |
| 심의 진행 절차와 소요기간·기한 | `references/timeline.md` |
| 심의 결정 유형과 그 다음 절차 | `references/decisions.md` |
| 승인 후 연구책임자의 의무 | `references/obligations.md` |

필요한 파일만 읽는다. 전부 읽지 않는다.

## 출력 형식

1. **해당 신청 유형** — 무엇을 신청하는 상황인지 한 줄로 확인
2. **제출서류 체크리스트** — 별지서식 번호 포함, "해당하는 경우"는 조건 표기
3. **절차 흐름** — 단계와 각 단계의 소요기간
4. **기한** — 기준일과 함께
5. **주의사항** — 놓치기 쉬운 것

체크리스트는 사용자가 그대로 복사해 쓸 수 있도록 `- [ ]` 형식으로 출력한다.

## 특히 자주 놓치는 것 (안내 시 확인)

- **신규심의**에 IRB 승인서가 필요하지만, **동시 심의 시 'IRB 심의 접수 증명서' + '연구계획서'로 갈음 가능** (제27조②7호)
- **지속심의는 만료 1개월 전까지**, IRB 승인 필요 과제는 **IRB 연장 확인자료 첨부** (제29조③④)
- **기간 연장에 데이터 항목·활용 방법·활용 주체·안전조치·반출 범위 변경이 수반되면 변경심의 병행** (제30조⑥)
- **반려된 건은 동일한 제목과 내용으로 다시 접수할 수 없다** (제21조①5호)
- **보완심의는 통보일로부터 1년이 초과하면 신청 불가** (제28조③)
- **심의 개최 7일 전까지 접수된 건**만 해당 회차에 상정 가능 (제16조⑥)

## 확인되지 않은 것

- DRB SOP는 "단, 시스템을 활용하는 경우 시스템에 제출하여야 함"을 반복 명시한다. **시스템 운영 여부와 접근 방법은 사무국 확인이 필요하다.**
- 심의 수당·자문료는 별표에 있으며 이 스킬 범위 밖이다.
- **위원회 규정**(SOP가 우선 적용한다고 명시한 상위 규정)은 미확보 상태다. 위원 구성·정족수 관련 질문은 사무국 안내로 넘긴다.
