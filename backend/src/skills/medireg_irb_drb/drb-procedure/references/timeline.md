# DRB 심의 절차와 기한

출처: 화순전남대학교병원 의료정보데이터심의위원회 표준운영지침서 ver1.0 — 제16~23조, 제25~32조

---

## 절차 흐름

```
연구책임자 제출
   ↓
사무국 서류 확인 (제16조①)
   ↓ 미흡 시
사전검토 → 수정·추가자료 요청 (제16조②)
   ↓ 연구책임자는 요청받은 날로부터 14일 이내 제출 (제16조③)
   ↓ 부득이한 경우 미제출 사유를 제출할 수 있음
행정간사가 접수 확인서[별지서식 39] 배부 (제16조④)
   ↓
전문간사가 정규심의·신속심의 대상 선별 → 위원장 보고 (제16조⑤)
   ↓
행정간사가 위원장에게 안건 상정 요청
   ※ 심의 개최 7일 전까지 접수된 신청 건에 한하여 상정 가능 (제16조⑥)
   ↓
┌─ 정규심의 (제25조) ────────────┐   ┌─ 신속심의 (제26조) ──────────┐
│ 사전 고지된 회의 일정에 따라 개최   │   │ 위원장이 신속심의 대상을 지정   │
│ 대면 회의 원칙(부득이 시 서면)      │   │ 전문위원 2명 이상, 서면회의     │
│ 재적 위원 과반수 출석으로 개회      │   │ 전문위원이 필요 판단 시         │
│ 안건마다 의사정족수 확인·기록       │   │ 정규심의 상정 요청 가능         │
│ 출석위원 과반수 찬성으로 의결       │   └────────────────────────────┘
│ 가부동수 시 1회에 한해 재논의       │
│ 안건 없으면 개최하지 않을 수 있음   │
└──────────────────────────────┘
   ↓
회의록 작성 [별지서식 42, 43] (제20조)
   ※ 회의일로부터 7일 이내 참석 위원 회람 → 위원장 확인 후 확정
   ↓
심의 결과 통보: 심의한 날로부터 15일 이내 (제21조②)
   ↓
(이의 있는 경우) 이의신청: 통보받은 날로부터 15일 이내 (제22조①)
   ↓
이의신청 처리결과 통보: 신청받은 날로부터 90일 이내 (제22조⑤)
```

## 전문위원의 역할 (제17조)

- 위원장이 연구 유형·분야에 따른 **전문성 및 이해상충**을 고려하여 **전문위원 2명 배정**
- 배정된 전문위원은 원칙적으로 **가명·익명처리 방법 및 활용환경 검토, 가명·익명처리 적정성 검토** 담당
- 검토 결과를 **보고서로 작성·제출** (별지서식 8, 9)

## 임시회의 (제25조⑥⑦)

정규심의 외 추가 논의가 필요하면 다음 중 하나로 소집할 수 있다.
1. 기관의 장이 소집을 요구할 때
2. 재적 위원 3분의 1 이상이 소집을 요구할 때
3. 그 밖에 위원장이 필요하다고 인정할 때

운영 방법은 정규회의와 같으며, 회의 개최 일정·심의 전문성 등을 고려하여 정할 수 있다.

## 기한 일람

| 항목 | 기한 | 기준일 | 근거 |
|---|---|---|---|
| 사무국 수정 요청에 대한 응답 | **14일 이내** | 요청받은 날 | 제16조③ |
| 안건 상정 마감 | **심의 개최 7일 전까지** 접수 | 심의 개최일 | 제16조⑥ |
| 위원회 상정 | **2개월 이내** (초과 시 사유 통지) | 심의신청 접수일 | 제18조② |
| 회의록 회람 | **7일 이내** | 회의일 | 제20조② |
| 심의 결과 통보 | **15일 이내** | 심의한 날 | 제21조② |
| **이의신청** | **15일 이내** | 심의 결과를 통보받은 날 | 제21조③12호, 제22조① |
| 이의신청 처리결과 통보 | **90일 이내** | 이의신청을 받은 날 | 제22조⑤ |
| **지속심의 신청** | **만료 1개월 전까지** | 승인유효기간 만료일 | 제21조③10호, 제29조③ |
| **종료보고** | **3개월 이내** | 데이터 활용 종료 | 제31조② |
| **보완심의 신청 제한** | **1년 초과 시 불가** | 심의 결과 통보일 | 제28조③ |

## ⚠️ IRB와 혼동하기 쉬운 기한

| 항목 | **DRB** | IRB (참고) |
|---|---|---|
| 심의결과 통보 | **15일 이내** | 업무일 기준 7일 이내 |
| **이의신청 기간** | **15일 이내** | 6개월 이내 |
| 종료보고 | **3개월 이내** | 20일 이내 (결과보고는 1년 이내) |
| 재심의/보완 신청 제한 | 통보일로부터 **1년 초과 시 불가** | 답변서 6개월 이내 |
| 지속(연장) 신청 | **만료 1개월 전까지** | 승인 만료일 최소 1개월 전까지 |

> 이의신청 기간이 **DRB 15일 vs IRB 6개월**로 크게 다르다. 사용자가 두 위원회를 함께 진행 중이면 반드시 구분해서 알린다.

## IRB 승인이 전제되는 과제의 연장 준비 순서

DRB 승인유효기간은 원칙적으로 **IRB 승인유효만료일에 따른다** (제29조②). 따라서 실제 준비 순서는 다음과 같다.

```
IRB 승인만료 D-60      IRB 연차지속심사 준비 시작
      ↓                (IRB 기준: 승인 만료일 최소 1개월 전까지 제출)
IRB 연장 승인 확보
      ↓
DRB 승인만료 D-30      DRB 지속심의 신청
                       + IRB 연장 확인자료 첨부 (제29조④)
```

**실효 만료일 = min(IRB 승인만료일, DRB 승인만료일)**

⭐ IRB 연장을 먼저 확보해야 DRB 연장 신청이 가능하다. 사용자가 DRB 만료일만 보고 준비하면 늦는다.
