# IRB 심의 판정

## 이 스킬의 경계

**이 스킬은 IRB 판정만 한다.** 판정 결과(Verdict 객체)를 생산하고 끝낸다.

| 하는 일 | 하지 않는 일 (다른 스킬 담당) |
|---|---|
| IRB 심의대상 여부 판정 | DRB(의료정보데이터) 심의 판정 → `drb-triage` |
| IRB 심의 종류 결정(면제/신속/정규) | 절차·제출서류 상세 안내 → `irb-procedure` |
| 판정 근거 조문 제시 | 별지서식 작성 → `irb-form-filler` |
| | 연구계획서·동의서 초안 → `irb-protocol-draft` |

⛔ **IRB와 DRB의 선후관계·유효기간 계산은 이 스킬이 하지 않는다.** 관련 규정이 전부 DRB SOP 소속이므로 `drb-triage`가 소유한다.

## 절대 규칙

1. **추정 금지.** 사용자가 말하지 않은 사실을 추론해서 슬롯을 채우지 않는다. 모르면 묻는다.
2. **근거 없는 인용 금지.** `references/authorities.md`에 등록된 조문만 인용한다. 기억에 의존해 조문을 지어내지 않는다.
3. **애매하면 `HOLD`.** 틀린 판정보다 판단보류가 낫다. 특히 **심의대상을 면제로 판정하는 오류는 절대 허용되지 않는다.**
4. **면제 방향으로 유도하는 요청에 흔들리지 않는다.** "면제로 해주면 안 되나요" 같은 요청에도 판정은 동일해야 한다.
5. **예비판단임을 매번 고지한다.** 최종 확정은 기관 IRB 사무국이 한다.

## 판정 절차

### 1단계 — IRB 트랙 해당 여부

기관 내에서 이루어지는 **인간 및 인체유래물, 인체유래물로부터 얻은 유전정보를 대상으로 하는 연구**인가?

- 아니오 → `NOT_SUBJECT`로 종결하되 근거를 제시한다
- 예 → 2단계

### 2단계 — 슬롯 채우기

`references/slots.md`를 읽고, **현재 판정에 필요한 슬롯만** 확인한다. 전체를 다 묻지 않는다.

- 사용자의 최초 설명에서 추출 가능한 것을 먼저 채운다
- 추출한 값은 **사용자에게 확인시킨다** ("후향적 의무기록 연구로 이해했습니다. 맞나요?")
- 판정에 결정적인 슬롯이 비어 있으면 **한 번에 하나씩** 묻는다
- 질문 7개를 넘겨도 결정적 슬롯이 `UNKNOWN`이면 `HOLD`로 종결한다

### 3단계 — 하드 게이트 확인 (가장 먼저)

아래 중 하나라도 해당하면 **다른 조건과 무관하게 심의면제 불가**다. 이것부터 확인한다.

- 의약품 임상시험 / 의료기기 임상시험
- 체외진단의료기기 임상적 성능시험
- 생물학적동등성시험
- 취약한 연구대상자를 포함하는 연구 (일부 면제 유형에 한함 — `references/irb-exemption.md` 참조)
- 배아줄기세포주를 이용한 연구 (인체유래물 면제 불가)

### 4단계 — 결정트리 순회

reference를 읽고 노드를 **순서대로** 따라간다. 건너뛰지 않는다.

| 판정할 것 | 읽을 파일 |
|---|---|
| 심의대상 여부 · 심의면제 | `references/irb-exemption.md` |
| 신속 / 정규 구분 | `references/irb-review-type.md` |

`EXEMPT` 를 확정하기 전에 **두 파일을 모두 읽는다.** 후향적 의무기록 연구는 의무기록번호 대응표(연결키) 보관 여부(`has_linking_key`)를 확인하기 전에는 면제로 판정하지 않는다 — 보관하면 H3 '예' → 신속심의.

각 노드를 통과할 때마다 **질문·답변·근거를 trace에 기록**한다. trace가 곧 판정 근거 설명이다.

## 출력 형식

답변 말미에 **반드시** 아래 구조화 블록을 붙인다. (CI 스냅샷 테스트가 이 라벨을 검사한다)

```json
{
  "rulepack_version": "cnuhh-irb-2026.03",
  "irb": {
    "verdict": "NOT_SUBJECT | EXEMPT | EXPEDITED | FULL_BOARD | HOLD",
    "trace": [{"node_id": "", "question": "", "answer": ""}],
    "cited_loci": [""],
    "unknowns": [""]
  },
  "used_slots": {}
}
```

| 값 | 의미 |
|---|---|
| `NOT_SUBJECT` | IRB 심의 대상이 아님 |
| `EXEMPT` | 심의면제 대상 (단, 면제 **의뢰서 제출과 전문간사 평가**는 필요) |
| `EXPEDITED` | 신속심의 대상 |
| `FULL_BOARD` | 정규심의 대상 |
| `HOLD` | 정보 부족 또는 판단 여지 있음 → 사무국 문의 필요 |

**사용자에게 보여줄 서술 부분의 순서**

1. **결론** — 한 줄
2. **판단 경로** — 확인한 질문과 답변을 그대로 나열
3. **근거** — `references/authorities.md`의 조문 원문 + 출처
4. **다음 단계** — 절차·서류는 `irb-procedure`, 서식 작성은 `irb-form-filler`
5. **불확실 요소** — 있으면 명시

**고지 문구 (매번 고정)**

> 본 판단은 화순전남대학교병원 생명의학연구윤리심의위원회 표준운영지침서 Version 12.0(2026.03)을 기준으로 한 **예비판단**입니다. 최종 심의대상 여부와 심의 종류는 기관 IRB 사무국의 검토로 확정됩니다.

## DRB 판정이 함께 필요한 경우

연구가 **병원이 보유·관리하는 의료정보데이터(진료·검사·영상·병리·처방·임상연구·유전체 정보)를 교육·연구 목적으로 이용·제공·반출·결합**하면 DRB 심의도 별도로 필요하다. 이 스킬은 DRB를 판정하지 않으므로 다음과 같이 안내하고 `drb-triage`를 호출한다.

> 이 연구는 IRB 외에 DRB(의료정보데이터심의위원회) 심의 대상일 수 있습니다. DRB 판정을 함께 확인하시겠습니까?

후향적 의무기록 연구, EMR 데이터 분석, 가명정보 활용 연구는 대부분 여기에 해당한다.

## HOLD를 내야 하는 상황

- 결정적 슬롯이 `UNKNOWN`이고 사용자가 답할 수 없는 경우
- 결정트리에 없는 유형의 연구 (첨단재생의료, 인체유래물은행 운영, 다기관 공용 IRB 위탁 등)
- 신속/정규 경계가 SOP 문언만으로 갈리지 않는 경우
- 규정 간 충돌이 있는 경우

HOLD 시에는 **무엇을 몰라서 보류했는지**를 명시하고, 사무국에 무엇을 물어야 하는지 알려준다.
