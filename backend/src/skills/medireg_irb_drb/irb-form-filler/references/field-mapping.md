# 슬롯 → 서식 항목 매핑

`irb-triage`가 만든 `used_slots`와 `trace`를 서식 항목에 그대로 옮긴다. **다시 판단하지 않는다.**

---

## CNUHHIRB 서식 1 — 심의면제 의뢰서 (인간대상연구 점검표)

점검표 문항은 triage의 결정트리 노드와 **1:1 대응**한다. trace만 있으면 자동으로 채워진다.

| 서식 문항 | triage 노드 | 슬롯 | 변환 |
|---|---|---|---|
| 질문 1 | `IRB.EXEMPT.H1` | `minimal_risk_to_public` | true → ☑예 / false → ☑아니오 |
| 질문 2 | `IRB.EXEMPT.H2` | `is_public_data` | true → ☑예 / false → ☑아니오 |
| 질문 3 | `IRB.EXEMPT.H3` | `collects_identifiable_info` | true → ☑예 / false → ☑아니오 |
| 질문 4-1 | `IRB.EXEMPT.H4` | `uses_existing_records` | true → ☑예 |
| 질문 4-2 | `IRB.EXEMPT.H4` | `subject_not_specified` AND NOT `collects_sensitive_info` | 둘 다 충족 → ☑예 |
| 질문 4-3 | `IRB.EXEMPT.H4` | `manipulation_type` | `non_invasive`→1번 / `contact_device_only`→2번 / `food_test`→3번 / `cosmetic_test`→4번 |
| 질문 5 | `IRB.EXEMPT.H5` | `vulnerable_subjects` | true → ☑예 / false → ☑아니오 |

## 서술형 항목 작성 지침

### 심의면제 사유

trace를 근거로 서술한다. **면제 근거 조항을 명시**한다.

템플릿:
> 본 연구는 [연구 유형]으로서, [면제 근거]에 해당하여 IRB SOP Ver 12.0 「5. 위원회의 심의면제 대상 연구 - [해당 항목]」에 따른 심의면제 대상에 해당합니다.
> 구체적으로 본 연구는 (1) 연구대상자 및 공공에 미치는 위험이 미미하고, (2) [H2 또는 H4 경로의 구체적 사유], (3) 개인식별정보를 수집·기록하지 않습니다.

예 (완전 익명화된 기존 자료 이용 연구 — 의무기록번호 대응표를 두지 않는 경우에 한함):
> 본 연구는 진료 목적으로 이미 생성된 기존 자료를 후향적으로 분석하는 연구로서, 연구대상자 및 공공에 미치는 위험이 미미하고, 의무기록번호 등과의 대응표를 보관하지 않아 직접·간접적으로 개인을 식별할 수 있는 정보를 수집·기록하지 않으며, 「연구대상자등에 대한 기존의 자료나 문서를 이용하는 연구」에 해당합니다. (IRB SOP Ver 12.0, 5-가(2)㈎)

⚠️ 후향적 의무기록 연구라도 **대응표(연결키)를 보관하면** 간접 식별 가능 정보를 기록하는 연구이므로 심의면제 의뢰서가 아니라 **신속심의 신청** 대상이다(`irb-triage` H3 참조). 면제 의뢰서를 쓰기 전에 `irb-triage` 판정이 EXEMPT 인지 확인한다.

⛔ **금지**: trace에 없는 사실을 사유에 쓰지 않는다. 예를 들어 "IRB 심의를 받을 필요가 전혀 없습니다" 같은 단정적 표현을 쓰지 않는다.

### 연구 배경·목적

사용자가 제공한 내용만 정리한다. 선행연구, 통계, 유병률 등을 **지어내지 않는다.** 근거가 필요하면 `[확인 필요: 선행연구 근거]`로 표시한다.

## DRB 서식

DRB 별지서식은 이 스킬이 다루지 않는다. `drb-form-filler`를 사용한다.

---

## 미확인 항목 처리

채워지지 않은 항목은 다음 형식으로 표시한다.

```
| 연구비 예산 | [확인 필요: 총 연구비 및 항목별 내역] | — |
```

그리고 초안 말미에 **확인 필요 항목을 모아서** 다시 제시한다. 사용자가 무엇을 채워야 하는지 한눈에 보이게 하는 것이 목적이다.

## 절대 지어내지 않을 항목

- 금액 (연구비, 보상액, 심의비)
- 인원 수 (연구대상자 수, 연구진 수)
- 날짜 (승인일, 만료일, 연구기간)
- 승인번호, 과제번호, 등록번호
- 기관명, 부서명, 담당자명
- 선행연구 문헌 및 통계 수치
