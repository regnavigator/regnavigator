# IRB/DRB 서식 작성

## 이 스킬의 경계

**이 스킬은 판정하지 않는다.** 어떤 서식을 쓸지는 `irb-triage`의 `verdict`가 결정한다.

| verdict | 열어야 할 서식 |
|---|---|
| `irb.verdict = EXEMPT` | CNUHHIRB 서식 1 (심의면제 의뢰서) |
| `irb.verdict = EXPEDITED` 또는 `FULL_BOARD`, `submission_type = new` | CNUHHIRB 서식 11 (연구계획심의 의뢰서) |
| `submission_type = amendment` | CNUHHIRB 서식 14 (연구계획 변경 심의 의뢰서) + 변경대비표 |
| `= continuing` | CNUHHIRB 서식 15 + 16 |
| 보완 심의 | CNUHHIRB 서식 13 (검토의견에 대한 답변서) + 변경대비표 |

⛔ **`verdict`가 없거나 `HOLD`이면 서식을 작성하지 않는다.** 먼저 `irb-triage`를 호출한다.
⛔ **스스로 심의 종류를 판단해서 서식을 고르지 않는다.**

## 절대 규칙

1. **모르는 항목은 비워두고 `[확인 필요: 항목명]`으로 표시한다.** 그럴듯한 값을 지어내지 않는다. 연구비 금액, 연구대상자 수, 기관 승인번호, 날짜 등은 특히 주의한다.
2. **체크박스·선택형 항목은 `verdict`의 `trace`에서 그대로 가져온다.** 다시 판단하지 않는다.
3. **서술형 항목만 작성한다.** 연구 배경, 심의면제 사유, 가명처리 사유 등.
4. **모든 산출물 첫 줄에 다음을 넣는다.**
   `[AI 생성 초안 — 연구책임자 검토 필수]`
5. **환자 개인정보(이름, 등록번호, 주민번호 등)를 입력받거나 문서에 기재하지 않는다.** 입력되면 즉시 마스킹하고 사용자에게 알린다.

## 작업 순서

1. `verdict`를 확인하고 대상 서식을 결정한다 (위 표)
2. `references/form-registry.md`에서 해당 서식의 항목 구조를 확인한다
3. `references/field-mapping.md`에서 슬롯 → 항목 매핑을 적용한다
4. 채워지지 않은 항목을 사용자에게 **한 번에 모아서** 묻는다 (하나씩 묻지 않는다)
5. 초안을 생성한다
6. 미확인 항목 목록을 별도로 제시한다

## 출력 형식

기본은 **마크다운 표 형태의 항목별 초안**이다. 사용자가 파일을 원하면 docx로 생성한다.

```
[AI 생성 초안 — 연구책임자 검토 필수]

# 심의면제(IRB Review Exemption) 의뢰서 초안
문서 기준: CNUHHIRB 서식 1 / IRB SOP Ver 12.0(2026.03)

## 1. 연구 정보
| 항목 | 내용 | 출처 |
|---|---|---|
| 연구과제명 | ... | 사용자 입력 |
| 연구책임자 | [확인 필요: 소속·직위] | — |
...

## 2. 심의면제 점검표
| 질문 | 응답 | 근거 |
|---|---|---|
| 질문 1. 연구대상자 및 공공에 미치는 위험이 미미한 연구입니까? | ☑ 예 | triage trace: IRB.EXEMPT.H1 |
...

## ⚠️ 확인이 필요한 항목
- 연구비 예산 내역
- 연구기간 시작일/종료일
```

## 서식 원본 확보 현황

**2026-08-21 IRB SOP Ver 12.0 원본(hwp)을 확보하여 서식 전문을 `references/form-registry.md`에 반영했다.**

| 서식 | 상태 |
|---|---|
| 서식 1 (심의면제 의뢰서) | 전문 확보 — 초안 작성 가능 |
| 서식 11 (연구계획심의 의뢰서) | 전문 확보 — 초안 작성 가능 |
| 서식 13~26 (답변서·변경·중간보고·연차지속·SAE·안전성·변동/위반·조기종료·종료·결과·기타·취소·이의·예상 못한 문제) | 전문 확보 — 초안 작성 가능 |
| 서식 29·30 (개인정보 제공·인체유래물등 제공 심의 의뢰서) | 전문 확보 |
| 위원·사무국용 서식(2~10, 12, 27, 31~43) | 작성 대상 아님 |

레지스트리에 없는 항목 구조는 **추측해서 만들지 않는다.** 서식 구조가 실제 배포본(E-IRB)과 다르면 사무국 배포본을 우선한다.
