# DRB(의료정보데이터심의위원회) 심의 대상 및 종류

출처: 화순전남대학교병원 의료정보데이터심의위원회 표준운영지침서 ver1.0 (승인 2026.06.16 / 시행 2026.07.01)

---

## STEP E1 — DRB 트랙 해당 여부 (노드 DRB.SUBJ)

### 용어 (제3조)

- **의료정보데이터**: 병원이 보유·관리하는 진료정보, 검사정보, 영상정보, 병리정보, 처방정보, 임상연구정보, 유전체정보 및 이와 관련된 데이터 일체
- **가명정보**: 개인정보의 일부를 삭제 또는 대체하는 등 추가 정보 없이는 특정 개인을 알아볼 수 없도록 처리한 정보
- **반출**: 병원 내부의 승인된 관리영역 밖으로 데이터를 이동하거나 외부기관에 제공하는 행위
  - **원시데이터 반출**: 가명처리된 개별 환자 단위의 데이터를 외부로 복제하여 이동
  - **분석결과 반출**: 원내 폐쇄형 분석실에서 분석 후 개인 식별이 불가능한 통계표·모델 가중치 등 결과물만 외부로 이동
- **재식별**: 가명정보 등을 이용하여 특정 개인을 알아보는 행위
- **데이터 가공공간**: 가명정보의 결합, 비식별 처리, 반출심사 및 반출 전 데이터 가공을 위해 병원이 운영하는 결합실 또는 비식별실
- **결합전문기관**: 관계 법령에 따라 서로 다른 개인정보처리자 간 가명정보의 결합 업무를 수행하도록 지정된 전문기관
- **연구승인기간**: 위원회 승인을 받아 데이터를 이용·제공·반출·결합하거나 분석결과를 산출할 수 있는 기간. **위원회가 승인한 시작일과 종료일 범위 내에서만 유효**

### 판정

병원이 보유·관리하는 의료정보데이터를 **교육·연구 등의 목적으로 이용·제공·반출·결합**하면 DRB 트랙에 해당한다.

- 미해당 → **`NOT_APPLICABLE`**
- 해당 → STEP E2

## STEP E2 — 심의 종류 (제24조)

위원회는 **데이터 처리의 위험성, 데이터의 종류 및 활용 방법** 등을 고려하여 심의를 분류한다. 심의 종류에는 **정규심의**와 **신속심의**가 있다.

### 정규심의 대상 (제24조③) → `FULL_BOARD`

1. 신규심의
2. 보완 후 정규심의
3. 종료심의
4. 이의신청

### 신속심의 대상 (제24조④) → `EXPEDITED`

1. 보완 후 신속심의
2. **변경심의** (기승인된 데이터 활용 건의 사소한 계획 변경)
3. **지속심의** (기승인된 데이터 활용 건의 연구 지속 가능 여부 확인)
4. 기관 협약 등을 통해 운영되는 **공용 데이터위원회**(명칭은 상이할 수 있음)의 승인을 받은 경우
5. **최소 위험 연구 환경**에 해당되는 경우 (폐쇄형 분석실에서 데이터 처리)
6. **심의면제**

> **주의**: DRB SOP에서 "심의면제"는 **신속심의의 한 유형으로 분류**되어 있다(제24조④6호). IRB의 심의면제와 구조가 다르므로, DRB에서 면제로 판정하더라도 "위원회 절차를 거치지 않는다"는 뜻이 아니다. `EXEMPT`로 판정하되 이 점을 반드시 안내한다.

---

## STEP E2-1 — 심의면제 기준 ⭐ (제32조⑦)

> 심의면제 신청은 행정간사가 접수받아 **전문간사가 면제대상 기준에 따라 판단**하여 **DRB 심의면제 확인서를 발급**한다.
>
> 1. **심의 면제대상 기준: IRB 승인된 건 중 가명처리가 필요없는 데이터**
> 2. **개인정보(개인을 식별할 수 있는 정보) 미포함**
> 3. **동의 후 수집한 데이터**
> 4. **증례보고서(CRF)를 통해 수집된 데이터**

### 판정 규칙

- 위 기준에 해당하면 → **`EXEMPT`**
- 1호는 **IRB 승인이 이미 있는 것을 전제**한다. `irb_approval_status = approved`가 아니면 1호를 적용하지 않는다
- 면제로 판정하더라도 **신청서를 제출하고 전문간사의 판단을 받아야 한다.** "아무것도 안 해도 된다"가 아니다
- 산출물은 **DRB 심의면제 확인서**다

⛔ **원시데이터 반출·외부 제공·가명정보 결합이 있으면 면제로 판정하지 않는다.** 1호가 "가명처리가 필요없는 데이터"를 전제하기 때문이다.

## STEP E3 — 신속심의 세부 기준 (제32조①)

신속심의 대상이 될 수 있는 과제는 다음 중 하나에 해당하는 경우이며, **전문위원 2명이 심의**한다.

1. **익명정보**이거나 연구대상자의 **데이터 활용 동의를 얻은** 경우
2. 연구대상자 등의 **개인정보 침해 위험이 없거나 미미한** 연구
3. 기승인되어 진행 중인 연구에 대한 **지속적인 검토**의 경우
4. **시정승인 또는 조건부승인** 결정을 통보받은 연구에 대한 재심의의 경우
5. **최소 위험 연구 환경**에 해당되는 경우 (폐쇄 환경 분석실에서 데이터 처리)

> 제32조② — 신속심의를 담당한 전문위원은 사안에 따라 **정규심의가 필요하다고 판단하면 정규회의로 상정을 요청할 수 있다.** 신속심의로 안내할 때 이 가능성을 함께 알린다.

### 전문위원 2명의 의견이 갈리면 (제32조④⑤)

- 사무국은 위원 간 심의 의견과 결과를 확인하고 **일부 조정 등 협의를 요청**할 수 있다 (④)
- 그럼에도 일치하지 않으면 최종 심의결과는 **요구 수준이 더 높은 결정 유형**으로 하며, **각 위원의 의견을 모두 제공**한다 (⑤)
  - 예: 2명이 각각 "승인"과 "조건부승인"으로 판단 → 최종은 **"조건부승인"**

⭐ 신속심의로 안내할 때 이 **보수적 합산 규칙**을 함께 알린다. 사용자가 "한 명만 승인하면 되는 것 아니냐"고 오해하기 쉽다.

### 신속심의 결과 통보 (제32조⑥)

사무국은 신속심의 결정 사항에 대하여 **심의한 날로부터 15일 이내**에 통보한다. (정규심의와 동일)

## 판정 시 함께 확인할 신호

아래 상황은 **위험도가 높아 정규심의(`FULL_BOARD`)로 기우는** 신호다. 해당하면 신속심의로 판정하지 말고, 애매하면 `HOLD`.

- **원시데이터 반출** (가명처리된 개별 환자 단위 데이터를 외부로 복제·이동)
- **외부기관 제공**
- **결합전문기관을 통한 가명정보 결합**
- 유전체정보 포함
- 재식별 위험이 우려되는 연결파일 사용

반대로 아래는 신속심의 방향의 신호다.

- 원내 **폐쇄형 분석실**에서만 처리하고 **분석결과만 반출**
- **익명정보** 사용 또는 연구대상자 **활용 동의** 확보

## 심의 결정의 종류 (제21조① / 제32조③)

판정 결과를 안내할 때 사용자가 받게 될 결정의 유형을 함께 알려준다.

**정규심의 결정 (제21조①)**

| 결정 | 의미 |
|---|---|
| 승인 | 제출 자료를 그대로 인정 |
| 시정승인(수정 후 승인) | 일부 수정 요구, 개인정보 보호 영향이 경미. **전문간사가 확인** |
| 조건부승인(수정 후 신속심의) | 중요한 수정 요구. 수정 사항의 적절성을 **신속심의에서 재확인** |
| 보완(보완 후 재심의) | 중대한 문제로 자료 보완·수정 요구. **정규회의에 상정하여 재심의** |
| 반려 | 개인정보 보호에 중대한 문제로 활용 불가. **동일한 제목과 내용으로는 다시 접수 불가** |
| 보류 | 정보 부족·추가 확인 필요. **다음 회의에 다시 심의** |
| 심의면제 | 관계 법령·규정 및 심의면제 기준에 따라 심의가 필요하지 않다고 판단 |
| 그 밖의 조치 | 위원회가 필요하다고 판단한 조치 |

**신속심의 결정 (제32조③)** — 6가지: 승인 / 시정승인(수정 후 승인) / 조건부승인(수정 후 신속심의) / **정규심의로 회부** / **심의면제** / **그 밖의 조치**(위원회 운영상 필요하다고 인정되는 사항)

## 위원회가 평가하는 3개 축 — 심의 기준표 ([별표 2])

위원회는 아래 기준표로 수집·처리·제공 여부를 심의하며, **항목별 평가결과가 '적정'인 경우 진행**할 수 있다 (평가결과: 적정 / 보완필요 / 부적정). 판정 안내 시 사용자의 계획이 어느 축에서 약한지 함께 짚는다.

| 축 | 평가 내용 |
|---|---|
| **목적의 적합성** | 목적의 적정성(통계·과학적 연구·공익적 기록보존 등) / 목적 달성을 위한 **구체적인 방법 제시** 여부 / 데이터 제공 심의 등 목적성 사전 검증 여부 |
| **안전성** | 가명정보 **결합 시 가명수준 약화** 등 개인 식별 우려 / 결합정보의 활용 가능성 / **목적범위 내** 데이터 신청범위·수준 여부 |
| **데이터 활용방법의 안전성** | 신청기관의 데이터 분석 환경(보유데이터, 분석자 소속기관, 데이터 관리방안 등) / **과거 개인정보 유출 등 침해사고 이력** / **파기계획의 구체성**(행정적·기술적 조치) |

> 자주 걸리는 곳: "필요하다"만 있고 **구체적 방법이 없는 목적 서술**, 목적 대비 **과다한 항목 신청**(안전성 축), **막연한 파기계획**(활용방법 축). 신청 전 3개 축 관점으로 자가 점검하게 안내한다.

## 데이터 활용기간 (제27조③④)

- 신규심의 신청 시 **데이터 활용기간을 명시**해야 하며, 활용 목적 달성에 필요한 **최소 범위**로 설정해야 한다
- 위원회는 활용기간의 적정성, 활용 목적과의 부합성, **종료 후 보존·파기계획**을 함께 검토할 수 있다

판정 시 사용자가 활용기간을 과도하게 설정했거나 파기계획이 없으면 이를 지적한다.
