# 연구계획서·동의서 초안

## 이 스킬의 접근 방식

**IRB가 심의할 때 무엇을 보는지를 목차로 삼는다.** 일반적인 논문 계획서 형식이 아니라, IRB SOP 18~31의 심의 항목을 역산한 구조로 작성하면 심의에서 지적받을 지점이 미리 채워진다.

승인 사례가 없어도 이 방식으로 작동한다. 사례가 확보되면 문체·수준 참조로만 추가한다.

## 이 스킬의 경계

- 심의 대상 여부·심의 종류 판정 → `irb-triage`
- 신청 서식 항목 채우기 → `irb-form-filler`
- 절차·제출서류 안내 → `irb-procedure`

## 절대 규칙

1. **선행연구·통계·유병률을 지어내지 않는다.** 근거가 필요한 자리는 `[근거 필요: ...]`로 비워둔다. 존재하지 않는 문헌을 인용하는 것은 이 스킬에서 가장 심각한 실패다.
2. **수치를 지어내지 않는다.** 표본 수, 연구기간, 예산, 채혈량 등은 사용자가 제공한 것만 쓴다. 표본 수 산정은 `[근거 필요: 표본수 산정 근거 — 검정력, 효과크기, 유의수준]`으로 표시한다.
3. **환자 개인정보를 문서에 넣지 않는다.**
4. **모든 산출물 첫 줄에** `[AI 생성 초안 — 연구책임자 검토 필수]`
5. **동의면제·동의서 관련 하드 게이트**: 의약품 임상시험, 의료기기 임상시험은 **동의 면제 대상에 포함되지 않는다** (IRB SOP 28). 해당하면 동의면제 사유서를 작성하지 않고 이유를 설명한다.

## 사용 방법

| 만들 것 | 읽을 파일 |
|---|---|
| 연구계획서 초안 | `references/protocol-outline.md` |
| 연구대상자 설명문·동의서 | `references/consent-outline.md` |
| 기존 계획서 검토 | 두 파일을 체크리스트로 사용 |

## 작업 순서

1. 연구 유형을 확인한다 (전향적 개입 / 관찰 / 후향적 자료분석 / 인체유래물 / 데이터 기반)
2. 사용자에게 최소한 아래를 확인한다. **한 번에 모아서 묻는다.**
   - 연구 목적과 가설
   - 연구 대상과 선정/제외 기준
   - 자료 수집 방법과 항목
   - 연구 기간
   - 취약한 연구대상자 포함 여부
   - 개인정보 처리 방식
3. 해당 outline을 목차로 초안을 작성한다
4. `[근거 필요: ...]` / `[확인 필요: ...]` 항목을 말미에 모아 제시한다

## 기존 원고 검토 모드

사용자가 이미 작성한 계획서를 주면, outline을 **체크리스트로 사용**하여 다음을 점검한다.

- 누락된 심의 항목
- 심의에서 지적받을 가능성이 높은 부분 (근거 부족, 위험 최소화 조치 미기재, 개인정보 보호 대책 부재 등)
- 계획서와 동의서 간 불일치 (연구기간, 대상자 수, 보상 내용, 위험 기술)

지적 시 **어떤 심의 항목에 걸리는지**를 함께 제시한다.

## 고지 문구

> 본 초안은 화순전남대학교병원 IRB SOP Ver 12.0(2026.03)의 심의 항목(18~31)을 기준으로 작성되었습니다. **모든 내용은 연구책임자가 검토·확정해야 하며, `[근거 필요]`로 표시된 항목은 반드시 실제 근거로 대체해야 합니다.**
