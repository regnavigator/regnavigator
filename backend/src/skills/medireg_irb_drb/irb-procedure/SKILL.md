# IRB 절차·서류·기한 안내

## 이 스킬의 경계

**이 스킬은 판정하지 않는다.** 심의 종류가 정해진 상태를 전제로 절차와 서류를 안내한다.

- 사용자가 자신의 심의 종류를 모르면 → **`irb-triage`를 먼저 호출**한다
- 서식을 실제로 작성해야 하면 → `irb-form-filler`
- DRB 절차는 → `drb-procedure`

## 절대 규칙

1. **서류 목록을 임의로 줄이거나 늘리지 않는다.** references에 있는 목록 그대로 제시한다.
2. **"해당하는 경우"로 표시된 서류는 그 조건을 함께 표기한다.** 조건 없이 필수처럼 제시하지 않는다.
3. **기한은 반드시 기준일을 명시한다.** "1개월 전"이 아니라 "승인 만료일 기준 최소 1개월 전".
4. ⚠️ **DRB의 기한 규정과 섞지 않는다.** 특히 **이의신청은 IRB 6개월 / DRB 15일**로 크게 다르다.

## 사용 방법

| 사용자가 알고 싶은 것 | 읽을 파일 |
|---|---|
| 신청 유형별 제출서류 | `references/irb-documents.md` |
| 심의 진행 절차와 소요기간·기한 | `references/timeline.md` |
| 심의 결정 유형과 그 다음 절차 | `references/decisions.md` |
| 승인 후 연구자의 의무 | `references/obligations.md` |

필요한 파일만 읽는다. 전부 읽지 않는다.

## 출력 형식

1. **해당 신청 유형** — 무엇을 신청하는 상황인지 한 줄로 확인
2. **제출서류 체크리스트** — 서식 번호 포함, "해당하는 경우"는 조건 표기
3. **절차 흐름** — 단계와 각 단계의 소요기간
4. **기한** — 기준일과 함께
5. **주의사항** — 놓치기 쉬운 것

체크리스트는 사용자가 그대로 복사해 쓸 수 있도록 `- [ ]` 형식으로 출력한다.

## 확인되지 않은 것

- IRB SOP는 **E-IRB 시스템**을 통한 전자 제출을 전제한다. 시스템 사용 권한(회원가입 후 부여)이 필요하다.
- 심의면제 제출서류가 SOP 「47. 다.(13)」과 「5. 다.(1)」에서 다르게 기재되어 있다. 실제 제출 전 사무국 확인을 권한다.
- 심의 수당, 자문료 등 비용 관련 사항은 별표에 있으며 이 스킬 범위 밖이다.
