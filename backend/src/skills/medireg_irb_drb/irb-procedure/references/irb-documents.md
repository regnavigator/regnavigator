# IRB 신청 유형별 제출서류

출처: 화순전남대학교병원 IRB SOP Ver 12.0(2026.03) — 「47. 심의신청」

## 공통 사항

- 서류작성 권한은 **E-IRB 시스템 회원가입 후 사용권한이 부여된 경우**에만 가능하다. 연구자, 의뢰기관 관리자가 지정한 과제담당자, 관리약사, 연구코디네이터(연구간호사)에게 부여할 수 있다.
- 연구책임자는 제출된 전자 서식 및 파일을 **최종 확인 후** 위원회에 제출한다.
- **SOP 최신버전의 양식**을 사용해야 한다.

---

## (1) 신규계획서 심의 의뢰

- [ ] 연구계획심의 의뢰서 **[CNUHHIRB 서식 11]**
- [ ] 연구계획서 요약 — **반드시 국문 제출**
- [ ] 연구계획서 — 첨부 자료 및 부록과 함께 제출, 작성자와 작성일 명확히 기입
  - 의약품·의료기기 임상시험 연구계획서는 **약사법 시행규칙 제31조, 의료기기법 시행규칙 제21조에 준하여** 작성
  - 정부에 제출하는 연구계획서(해당하는 경우)
- [ ] 연구대상자 설명문
- [ ] 연구대상자 동의서 — *동의 면제가 가능한 경우에 한하여* 연구대상자 동의면제사유서
- [ ] 증례기록서
- [ ] 연구대상자 보상규약 *(해당하는 경우)*
- [ ] 연구대상자에게 제공되는 서류 (환자일지, 설문지 등)
- [ ] 연구대상자 모집문건 *(해당하는 경우)* — 모집절차, 모집매체, 광고문구. **생동성시험은 반드시 제출**
- [ ] 식약처 또는 주관연구기관 승인서 *(해당하는 경우)* — 타 위원회·정부부처에서 심의된 경우 과거의 중요한 결정(부결·수정보완된 계획서)과 원안 수정 내용 표시, 과거 부정적 결정의 이유 포함
- [ ] 시험약(시험의료기기)의 개요 *(해당하는 경우)*
- [ ] 안전성 정보 및 임상시험자자료집 *(해당하는 경우)* — 제제학적·약리학적·약물학적·독성학적 자료를 포함하는 안전성 자료요약 및 임상경험 요약. **시판 의약품은 제품설명서로 대체 가능**
- [ ] 제조(수입)품목 허가증 *(해당하는 경우)*
- [ ] 연구책임자의 교육·수련·경험 등을 포함한 최근 이력
- [ ] 연구자 교육 이수증 사본
  - 의약품 임상시험(PMS 제외) 수행 시: **최근 1년 이내** 이수한 식약처 종사자교육 수료증
  - 그 외 연구: **최근 3년 이내** 이수한 연구자 윤리교육 수료증(KGCP)
  - E-IRB 교육이수 관리에 유효한 수료증이 등록되어 있으면 제출 면제 가능
- [ ] 연구비 예산 내역서

> **제출 마감**: 신규계획서 심의 서류는 **회의 개최 12일 전까지** 제출한다 (SOP 32-나). 정규심사는 **월 1회, 첫 번째 화요일 개최가 원칙**이다 (49-나).

- [ ] 심의면제 의뢰서 **[CNUHHIRB 서식 1]**
