# MEDIREG AI — 변경 이력

MEDIREG AI 는 의사·RA/QA·인허가 컨설턴트를 위한 **한국어 의료 규제 상담 서비스**다.
백엔드(FastAPI + 자체 tool-loop)와 프런트엔드(Next.js)의 변경을 한 타임라인으로 적는다.
"무엇을 왜 바꿨는지"와 실측 수치(지연·recall·테스트 수)를 중심으로 한다.

- 정렬: 월 단위, 최신이 위. 월 안에서는 영역별로 묶었다.
- 태그: **(back)** 백엔드, **(front)** 프런트엔드, 표시 없음 = 양쪽 또는 운영.
- **교훈** 항목은 실제로 난 사고를 "무엇이 실패했나 → 원인 부류 → 조치"로 줄인 것이다.
- 설계 정본: `backend/docs/spec/ADR-0001-fastapi-migration.md`(langgraph → FastAPI 이전),
  `backend/docs/spec/ADR-0002-qdrant-int8-quantization.md`(검색 int8 양자화),
  `backend/docs/guide/architecture.md`, 프런트 계약 `backend/docs/contracts/frontend_chat_v2.md`.

### 법무·고지 (결정적 부착)
- **채팅 면책을 코드가 붙인다** (10-03, back): `legal.py` 가 처음부터 "결정적 부착"을 선언했지만 실제로는 프롬프트가
  LLM 에게 "세션 1회 쓰라"고 지시할 뿐 부착 코드가 없었다 — 2턴째부터 면책이 없었다. 인용 ≥1 턴마다
  `append_chat_disclaimer`, 의견서엔 `append_report_disclaimer`. 프롬프트 지시는 삭제(v33).
- **기능별 범위 고지** (10-03, back): 판례·조례·해석례·영향범위처럼 "빠진 것이 있을 수 있다"가 핵심 한계인

  `ChatRequest.doc_kinds` 구조화 필드로.
- **현행본 미보유 고지** (10-05, back): 코퍼스가 시행예정본만 가진 법령(88개, 의료법·약사법 포함)은 모델이

  시행예정이면 `※ 현행본 고지:` 를 붙인다. 같은 법령의 현행 조문이 하나라도 인용되면 붙이지 않는다.
- **법무 문서 정정** (10-03): 처리방침 서비스명(`MEDIREG AI`→RegNavigator), 보호책임자·국외이전·기밀 경로 추가,
  `LEGAL_VERSION` 2026-10-03 으로 재동의. 랜딩·신뢰도 배지에서 **없는 웹 화이트리스트 검증** 설명 삭제,

  보고서를 만들면 읽음 처리돼 줄어든다(열람으로는 안 줄어듦, 사용자 결정). 스레드 안 입력창은
  **관찰 목록·변경 확인(배지) + 조문 개정 영향 범위** 두 버튼만(기밀·서면·심층보고서·기능연계 숨김, 첨부 유지).
  대상 이름 필수(422). `/alerts` 사이드바 아이콘 제거(페이지 유지). 백엔드 `GET /monitor/threads` 에
  `changed_count·kinds·latest_alert·last_checked_at`, `chat_threads.monitor_checked_at`(점검 시각 — 변경 0건이어도
  기록), `POST …/report` 가 `marked_read` 반환. 실측: 미읽음 2건 심기 → 헤드라인 "대상 1 · 조문 2건" → 보고서
  생성 → "확인 안 한 변경 없음".
- **연계 중 "일시적인 오류" 로 답변이 끊기던 것** (10-06, back/front): 원인은 컨텍스트 길이가 아니라 **자동
  이어쓰기**. 답변이 `max_tokens`(4096)에서 잘리면 부분 답변을 assistant prefill 로 넣어 이어 받는데, 현재
  모델 경로(`:8787` 프록시)가 prefill 을 400 으로 거부 → 예외가 턴 전체를 실패로 끝내 **이미 스트리밍된
  4천 자가 버려졌고**, 연계 실행기는 부분 텍스트가 있었다는 이유로 성공으로 보고 다음 단계로 넘어갔다.
  수정: prefill 거부면 연장을 포기하고 부분 답변을 `truncated` 로 확정([이어서 작성] 버튼) · 실행기는
  `error` 이벤트로 끝난 단계에서 멈춤. 재현 실측: 같은 400 발생 → `done` 4,405자 + `truncated`, 오류 없음.
