# 사용 가이드

의료기기 규제·GMP·법령 자문 AI 어시스턴트.
의사·RA·QA·인허가 담당자·법무·규제 컨설턴트가 *공식 근거가 박힌 답변*을 빠르게 받기 위한 도구입니다.

> 이 가이드는 *앱을 쓰는 분*을 위한 문서입니다. 개발 지식은 필요 없습니다.
> 앱이 이미 켜져 있다고 가정합니다(브라우저로 접속 가능한 주소가 있어야 합니다 — 사내 관리자에게 받으세요).

---

## 1. 처음 시작 — 설정 (1회)

브라우저로 앱 주소(예: `http://medi-reg.사내도메인` 또는 `http://localhost:3000`)에 접속하면 **설정 창**이 자동으로 뜹니다.

| 입력 칸 | 무엇을 넣나 | 어디서 받나 |
|---|---|---|
| **Deployment URL** (서비스 주소) | 백엔드 API 주소 | 관리자 |
| **Assistant ID** (어시스턴트 ID) | 사용할 에이전트 식별자 | 관리자 |
| **LangSmith API Key** (인증 키) | 이 앱을 쓸 권한 키 | 관리자 |

세 값을 모두 입력 → **저장**. 화면이 닫히고 메인 화면으로 갑니다.

> 입력값은 **현재 사용 중인 브라우저에만** 저장됩니다. 다른 PC·다른 브라우저에선 다시 입력해야 합니다.

설정을 다시 열려면 화면 오른쪽 위 ⚙ (톱니바퀴) 아이콘.

## 2. 첫 질문 — 한 사이클

### 2.1 새 대화 시작
화면 오른쪽 위 **+ 새 대화** 버튼 클릭. 왼쪽 사이드바에 새 대화 한 줄이 생기고, 가운데 본문이 비어집니다(환영 화면).

### 2.2 질문 입력
화면 아래 **입력창**에 질문을 적습니다. 예시:

> *의료기기 광고 시 표시해야 하는 사항은?*
> *2024년 식약처 GMP 가이드라인에서 PMS 절차가 어떻게 바뀌었어?*
> *수입 IVD 기기의 임상시험 면제 조건을 알려줘.*

키 동작:
- **Enter** — 전송
- **Shift + Enter** — 줄바꿈
- **Esc** — (답변 중일 때만) 정지

### 2.3 진행 보기 — *단계 카드 (한 칸 carousel)*
질문을 보내면 답변이 나오기 전에 **단계 카드 한 칸**이 채팅 안에 자리를 잡고, 에이전트가 *지금 무엇을 하는지* 보여줍니다. 새 단계가 도착하면 그 칸의 내용이 *최신 단계*로 자동 갱신됩니다.

```
● 법령 검색: 의료기기 광고 표시      1.2s  3/5  ‹ ›
도구  rag_search
쿼리  "의료기기 광고 심의 기준 2024"
발견한 출처  [1] 식약처 가이드라인 …
```

| 점 색 | 의미 |
|---|---|
| 🟡 노란 (깜빡) | 진행 중 |
| 🟢 초록 + ✓ | 완료 |
| 🔴 빨강 + ⚠ | 오류 |

**탐색 — 카운터 옆 `‹` `›` 화살표**로 이전/다음 단계를 볼 수 있습니다. 카운터(`3/5`)를 클릭하면 *최신 단계로 자동 따라가기* 모드가 다시 켜집니다 (수동 탐색 후 한 번이라도 화살표를 누르면 자동 모드 꺼짐).

### 2.4 답변 읽기
단계가 끝나면 답변이 본문에 등장합니다. 마크다운(목록·표·코드 등)이 보입니다.

본문 안 **[1]·[2]** 같은 *파란 번호*는 **인용 표시**입니다.

- **클릭하면** 인용된 출처(법령·고시·웹문서)의 메타와 본문 발췌가 *오른쪽 패널*에 뜹니다 — 발행기관·일자·조항·페이지·문서ID와 인용 스니펫. 폐지된 근거는 빨간 배지, 변경 예정은 주황 배지로 구분.
- 답변 아래 **References 박스**에 모든 인용이 번호 순으로 정리되어 있습니다.
- 각 인용 옆 **↗** 또는 **⚖**(저울) 아이콘을 누르면 *원문이 새 탭으로* 열립니다. ⚖는 **법령정보센터(law.go.kr)** 으로 바로 이동 — 의료기기법·식약처 고시 등 한국 법령은 분야별 deep-link(`/법령/...`, `/행정규칙/...`)로 자동 연결됩니다.
- 우측 패널 헤더 ✕ 또는 다른 인용 클릭으로 닫거나 전환할 수 있습니다.

### 2.5 폐지된 근거 — 주의
인용 chip이 **빨간 배경 + 취소선** + "폐지된 근거" 툴팁이면, 그 출처는 더 이상 유효하지 않습니다.
> 답변에 폐지 근거가 섞여 있으면 *현재 시점 적용*에 신중하세요. 개정·후속 고시를 별도 검색하거나 다시 질문해 주세요.

## 3. 대화 관리

화면 왼쪽 **사이드바**:

| 동작 | 방법 |
|---|---|
| 다른 대화로 전환 | 항목 클릭 |
| 대화 이름 바꾸기 | 항목 더블클릭 → 이름 입력 → Enter |
| 대화 삭제 | 항목 위 호버 → 휴지통 아이콘 → 확인 |
| 새 대화 | 사이드바 위 **+ 새 대화** 버튼 |
| 대화에 답변 대기 중인 게 있으면 | 항목 우측에 빨간 점 |

대화는 **자동 저장**됩니다 — 삭제하지 않는 한 다시 와서 이어서 질문할 수 있습니다.

> 대화 목록은 *서버*에 저장됩니다(브라우저가 아닙니다). 따라서 다른 PC에서도 같은 계정으로 접속하면 같은 대화 목록이 보입니다.
> *현재 1차에선 단일 사용자 가정. 다중 사용자/회원 기능은 후속 버전 예정.*

## 4. 자주 하는 질문 (FAQ)

**Q. 답변에 인용이 하나도 없습니다. 신뢰해도 되나요?**
→ 인용 없는 답변은 *공식 근거가 부족하다*는 뜻입니다. 같은 질문을 더 구체적으로 다시 묻거나, 다른 키워드를 시도해 보세요.

**Q. 같은 질문에 다른 답이 나옵니다.**
→ 검색 결과·LLM 응답이 매번 동일하지 않을 수 있습니다. 답변의 *인용 출처를 직접 확인*하는 게 핵심입니다 — 답변 텍스트가 아니라 출처가 진실원천입니다.

**Q. "에이전트와의 연결이 끊겼습니다" 배너가 떠요.**
→ 화면 위 **[재시도]** 클릭. 계속 떠있으면 관리자에게 백엔드 상태 문의.

**Q. 화면이 멈췄어요 / 빈 화면이에요.**
→ 새로고침(F5). 그래도 안 되면 ⚙ 설정 다이얼로그 다시 열어 값 재입력.

**Q. 모바일에서 쓸 수 있나요?**
→ *읽기는 가능*하지만 입력·대화 관리는 데스크톱(1280px 이상) 권장입니다.

**Q. 답변을 누구한테 보내려면?**
→ 답변 본문 영역을 마우스로 선택해 복사. 코드/표는 우측 상단 *복사* 아이콘.

**Q. 영어로 질문해도 되나요?**
→ 입력은 한·영 혼용 가능. 답변은 한국어로 옵니다.

**Q. 답변이 너무 길어요. 짧게 받고 싶어요.**
→ 질문에 *"한 문장으로"*, *"표로 정리해줘"*, *"핵심만 3줄"* 같은 단서를 추가하세요.

## 6. 알아두면 좋은 한계 (현재 버전)

이 앱은 *현재 알파 단계*입니다. 다음 항목은 *아직* 동작하지 않거나 제한적입니다:

- **인용 칩 클릭 시 출처 패널** — 화면 우측에 출처 메타·스니펫·법령정보센터 링크 표시. ✓ 가능
- **산출물(보고서) 풀뷰 패널** — 카드 클릭 시 우측에 markdown 풀뷰. ✓ 가능
- **다크 모드 정밀 튜닝** — 시스템 다크 모드일 때 보기 가능하나 정밀 색은 후속.
- **회원 가입·로그인** — 1차 단일 사용자(관리자가 받은 키 1개로 운영). 다중 사용자는 v2.
- **모바일 정밀 UI** — 1차 데스크톱 우선.
- **DEMO 배지** — 화면 좌측 상단 로고 옆에 *DEMO* 배지가 보이면 더미 데이터 모드입니다. 실제 답변이 아닌 UX 점검용 스크립트 응답이 표시되므로 임상·규제 판단에 사용하지 마세요.
