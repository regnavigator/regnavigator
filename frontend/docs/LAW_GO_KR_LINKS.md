# LAW.GO.KR 링크 가이드

법령정보센터(`https://www.law.go.kr`) deep-link 구성 규칙. 13개 분야별 URL 패턴.

> 본 문서는 *backend·frontend 공용 reference*. backend가 `Citation.url`을 발행할 때, frontend가 `lawLink.ts`에서 fallback 도출할 때 모두 본 패턴을 따른다.
> **백엔드가 정확한 URL을 줄 수 있으면 항상 backend가 우선** — 본 도출은 fallback.

## 14. URL 인코딩 규칙

- Hangul은 raw로 둬도 브라우저가 처리하지만, **`encodeURIComponent`로 안전하게** 인코딩하는 것을 기본으로.
- 공백·특수문자(`(`, `)`, `,`, `「」` 등) 포함 시 인코딩 필수.
- 슬래시(`/`)는 path 구분자라 인코딩하지 않는다 — 각 segment만 인코딩.

## 15. Frontend 측 fallback 도출 — `lawLink.ts`

backend가 `citation.url`을 안 주는 경우 frontend가 도출. heuristic + 패턴 매칭:

| 단서 | 분야 |
|---|---|
| title 끝에 `법`·`시행령`·`시행규칙`·`법률` | **법령** |
| title에 `고시`·`예규`·`훈령`·`규정`·`지침` | **행정규칙** |
| title에 `조례`·`규칙` + publisher가 지자체(서울특별시·강남구 등) | **자치법규** |
| title에 `조약`·`협정` | **조약** |
| publisher가 `대법원` 또는 title에 `판결`·`판례` | **판례** |
| publisher가 `헌법재판소` 또는 title에 `위헌소원`·`헌재` | **헌재결정례** |
| title에 `법령해석`·`해석례` | **법령해석례** |
| title에 `행정심판`·`심판` | **행정심판례** |
| title에 `별표 X` 또는 `서식 X` 패턴 | **별표서식** (모법 카테고리에 따라 분기) |

분야 검출 후 path 구성:
- 기본: `/<분야>/<제목>`
- 조 단위 deep-link 가능 시(법령): `/<분야>/<제목>/<article>`
- 검출 실패 시 fallback: `https://www.law.go.kr/lsSc.do?query=<title>` (검색 페이지)

## 16. Backend 권장사항

- **Citation 발행 시 정확한 deep-link을 `citation.url`에 넣어주는 것이 가장 좋음**.
- 가능하면 `Citation`에 분야 힌트 필드 추가 검토 (예: `doc_category: '법령' | '행정규칙' | ...`). frontend의 heuristic 의존도를 낮출 수 있음. 본 결정은 `medi-back/02_INTERFACE.md` 측에서.
- 공포번호·시행일자가 있으면 쿼리 string으로 정확한 시점 deep-link 가능 (`/법령/<명>/(공포번호,공포일자)`).
